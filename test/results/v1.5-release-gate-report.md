## Bugs found and fixed (`internal/source/tailer/tailer.go`)

The gate was doing its job: the new lifecycle/leak/backpressure suites caught
**four real concurrency defects** in the event/hybrid tail paths. All are fixed;
the full `-race ./...` regression is green afterward.

1. **`tt.Tell()` data race (hybrid).** `tailFileHybridEvent` called
   `hpcloud/tail.Tell()`, which does an unlocked `tail.file.Seek` + reads
   `tail.reader` — racing the library's own `openReader()` reopen (fired on
   delete-with-ReOpen and always on truncate). Caught by `-race` on C2/D3.
   **Fix:** drop `Tell()`; track the consumed offset by byte-counting
   (`lastSize += len(line)+1`), which matches `Tell` for newline-terminated
   records and self-corrects via the poll-drain reseek.

2. **`close(out)` send race (all modes).** `Run` closed the output channel
   without waiting for per-file tail goroutines, so a goroutine could `out<-line`
   after `close(out)`. Caught by `-race` on D3 (poll/event).
   **Fix:** a `sync.WaitGroup` tracks every per-file goroutine; `Run` does
   `wg.Wait()` before `close(out)`.

3. **`Stop()` deadlock under backpressure (event+hybrid).** When `out` is full
   the consumer stops draining `tt.Lines`; hpcloud/tail's internal goroutine then
   parks on `tt.Lines <- line`, so the deferred `tt.Stop()` (Kill+Wait) blocks
   forever and the (possibly unlinked) fd is never released. Caught by F2.
   **Fix:** `stopTail()` drains `tt.Lines` concurrently while stopping, so the
   internal goroutine observes the kill and exits.

4. **Line lost under backpressure (hybrid).** `lastSize` was advanced when a line
   was pulled from the lib, not when forwarded; on a stall→poll mode switch the
   in-hand, not-yet-forwarded line was skipped. Caught by F1/hybrid.
   **Fix:** advance `lastSize` only **after** a successful `out<-line` (or for a
   skipped blank line); on ctx-cancel mid-send, leave it so poll re-reads the line.

I1/I2 (the spec's code-review items) hold in the fixed code: event/hybrid
`return` + `stopTail()` on delete (no `continue` empty-wait); inode-swap is the
stat-ticker `os.SameFile` path; `startFile`'s deferred cleanup does
`delete(t.tailed, path)`.

## DocumentDB cross-check

`internal/dao/store` integration suite ran green against the real DocumentDB
cluster (via SSH tunnel through the EC2 bastion, full TLS validation): 11 identity
1:1/1:N tests + all `_ts`-guarded write models (UserSet/SetOnce/Add/Del/Append/
UniqAppend/Unset, Event Track/Update/Overwrite, DeadLetter, EnsureIndexes). The
`test/` daemon package skipped on DocumentDB only because its `pingMongo` uses a
2 s connect timeout (vs. the cross-region TLS handshake latency) — not a failure;
those same components pass on mongo:6 and their storage layer passes on DocumentDB.
